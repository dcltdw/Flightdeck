Flightdeck turns your run screen into a heads-up data field. Add it to a run profile and swipe to it like any other data page — it's additive and doesn't replace Garmin's native screens.

Live metrics, at a glance:
• Elapsed time, front and centre
• Lap pace and lap distance either side
• Session distance below

Four themes, dark or light:
• Cockpit — warm HUD with corner reticles and a scan line
• Bridge — an octagon console frame
• Bulkhead — bold type with wall striping
• Phosphor — a green-CRT radar scope

Pick your theme and dark/light mode from the Garmin Connect app.

Make it yours, all from the Garmin Connect app:
• Choose any metric for each field — pace, distance, heart rate, cadence, elevation, calories, speed, and their lap and average variants
• Pick how many fields to show — 1 to 5. Fewer fields mean bigger, easier-to-read numbers. The default is a 4-field compass: one value at the top, one at each side, one at the bottom
• Every layout keeps its own field choices, so setting up one leaves the others alone
• Turn short field labels on or off

Adding it to a run:
Flightdeck is a data field, not a watch face — add it to a run profile's data screens, and give it a screen of its own (a single-field layout) so it can fill the display:
• On the watch: MENU → Settings → Activities & Apps → your run profile → Data Screens → Add New → Layout: single field → Connect IQ Fields → Flightdeck.
• In Garmin Connect: your device → Activities & App Settings → run profile → Data Screens → add a single-field screen → Connect IQ → Flightdeck, then sync.
During a run, scroll to it like any other data page.

• Custom bitmap typography for a crisp, distinctive look
• Requests no permissions
• Runs on AMOLED running watches: Forerunner 70 / 165 / 170 / 265 / 265S / 965 / 970, Fenix 8, Epix 2, Venu 3 / 3S

What's changed

0.2.0 — A bigger, bolder default screen. The 4-field view is now a compass: one large value at the top, one at each side, and one at the bottom, with much larger numbers than the old corner grid — and it is the new default layout. If you never changed the layout setting you will see a 4-field screen instead of the 5-field one; the 5-field grid is still one setting away in Garmin Connect. Each layout now keeps its own field choices independently. Please note: because the field settings changed shape, custom field choices from earlier versions are reset to their defaults — just set them again in Garmin Connect. Your theme, mode, layout and label settings are kept. Times past an hour now keep their size on every layout. The light themes are easier to read at a glance too: Bridge, Bulkhead and Phosphor now colour their values so the top and bottom of the screen read as one pair against contrasting sides, the way Cockpit already did — Phosphor light in particular used to render every value in nearly the same teal. Still requests no permissions.

0.1.5 — New look for the numbers: the digits are drawn from a new source typeface, most noticeably a slashed zero. Sizes and positions are unchanged, so every field sits exactly where it did. Flightdeck is also now open source under the GPL-3.0-or-later licence. Still requests no permissions.
